# Isolated Pueue CPU evidence

Pueue 4.0.4 Linux release binaries were obtained from [the official release](https://github.com/Nukesor/pueue/releases/tag/v4.0.4); SHA-256 values and sanitized results are in `pueue-cpu-evidence.json`. No vendor signature or independent supply-chain verification is claimed. The local test used a dedicated `/mnt/ssd/genos2/workspace/herdr-ml-pueue-test` directory and distinct `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, and `XDG_RUNTIME_DIR`; no host service was changed. The daemon was shut down at the end.

The test-side helpers are retained as `pueue-task.py`, `pueue-serialization-test.py`, `pueue-runtime-test.py`, and `pueue-crash-test.py`. The serialization helper was subsequently changed to pass an environment allowlist because Pueue persists client environment variables in task state; the observed run used the inherited environment. The isolated test directory was restricted to its owner, and raw task state was not published. They use absolute paths and must be adapted to a fresh isolated test directory before reproduction; the serialization test deliberately refuses an existing events file. First start `pueued` in the foreground with all three isolated XDG directories, put the matching `pueue` binary on PATH, and run `bash scripts/setup-gpu-queue.sh` with the same XDG environment. Then execute the helpers with the pinned Python 3.10 interpreter. Never point these helpers at a production Pueue socket: the crash test deliberately kills its own isolated daemon.

`pueue-serialization-test.py` submitted two synthetic project labels, not actual researchctl projects; ordered start/end markers showed non-overlap in `gpu0` with parallelism one. A clean daemon restart preserved both successful task records. `pueue-runtime-test.py` submitted a separate fingerprint comparison as a CPU task using an absolute interpreter, and it completed successfully. `pueue-crash-test.py` killed its own isolated daemon while a CPU task was running; after restarting, Pueue reported the task as `Killed`. This does not show that researchctl reconciles the run, that detached descendants have terminated, or that a GPU slot may be released. Queue execution remains blocked.
