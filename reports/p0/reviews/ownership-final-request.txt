## Remaining MEDIUM

### MEDIUM-A: If the controller dies without running its handler, the workload is orphaned and the registry cannot identify it

**Root cause.** The child is started with `start_new_session=True`, so it does not share the controller's fate.

- If the controller dies in a way that bypasses its handlers, the group keeps running with no supervisor. Examples are SIGKILL, the OOM killer, SIGQUIT (Ctrl-\ is not handled), or an interpreter crash.
- The `run` row stores only the controller's identity (`owner_pid`, `owner_boot`, `owner_start`), never the child's.
- `reconcile` therefore reports `UNKNOWN` "may own live descendants", with nothing an operator or tool can check that claim against.

Liveness and reclaim are intentionally absent, but this is a separate gap: without the child's identity, an `UNKNOWN` state can never be resolved with evidence.

**Reproduction (by reading).** Use the setup of `_cancel_stubborn_descendant`, but call `proc.kill()` instead of sending a handled signal.
- The child and grandchild survive.
- `inspect()` shows `RUNNING` with no child pid or pgid.

**Fix.**
1. Record `child_pid`, `child_pgid` (equal to `child_pid`), `boot_id`, and the child's `/proc/<pid>/stat` field 22 start time in the same transaction as `DISPATCHING→RUNNING`.
   - Pass these through `advance()`, or add a dedicated `set_running(folder, token, child_identity)`.
   - Use a new `CREATE TABLE IF NOT EXISTS child(...)` table rather than new `run` columns. Existing `registry.sqlite3` files would not gain new columns through the current `CREATE TABLE IF NOT EXISTS run` DDL.
2. In `reconcile`, report whether that pid with that start time is still alive, and list any `/proc/*/stat` entries whose pgrp equals `child_pgid`. This is evidence only, not reclaim.
3. Add SIGQUIT to the handled set.
4. Optionally set `PR_SET_PDEATHSIG(SIGKILL)` on the direct child, re-checking `getppid()` after the call to close the race. This does not cover grandchildren.

**Residual.** A SIGKILL that lands between `Popen` and the RUNNING commit still leaves `DISPATCHING` with no identity. This is inherent, and `reconcile` already treats `DISPATCHING` as `UNKNOWN`.

**Acceptance tests.**
- After SIGKILL to the controller, `inspect()` exposes the child's pgid and start time, and `reconcile` reports that the group is alive.
- After the test kills the group, `reconcile` reports that it is gone.
- SIGQUIT to the controller results in `INTERRUPTED` with no survivors.

### MEDIUM-B: `COMPLETED` is recorded even when the controller had to SIGKILL surviving descendants

**Root cause.** On a normal leader exit, `stop_and_reap()` unconditionally sends `killpg(SIGKILL)`, which is correct for containment. However:

- The result written to the registry and `result.json` contains only `exit_code` and the log hashes.
- If a background writer, data loader or checkpoint flusher was still running in the group, the controller truncated it.
- The run is then recorded as `COMPLETED exit=0`, with no indication that the controller cut the work short.
- `test_normal_leader_exit_stops_same_group_descendant` checks that the grandchild dies, but not what was recorded.

This is not a false completion by the leader's contract, but the terminal record is misleading. Runs are diagnostic only, which limits the impact.

**Fix.**
1. Before the SIGKILL in the normal-exit path, while the zombie leader still pins the pgid, scan `/proc/*/stat` for pgrp equal to `child.pid` and pid not equal to `child.pid`.
2. Record the result as `descendants_terminated: <count or pids>`.
3. Decide on a policy and test it. Either downgrade to `FAILED` with `detail="descendants_killed"`, or keep `COMPLETED` but make the flag mandatory in the result schema.

**Acceptance test.** Rerun the existing normal-exit test, and assert that `inspect()['result']` records the terminated descendant. Also assert the chosen terminal state.

## New / remaining LOW

1. **A fence can exist without a registry row.** In `claim()`, an exception after the `mkdir` and before `COMMIT` leaves `execution.claim` with no `run` row. Examples are `_connect` failing on a lock timeout, ENOSPC, or a corrupt database, or the directory `fsync` failing.
   - This fails closed: retries hit `EEXIST`, and `reconcile` reports `UNKNOWN`.
   - However, `cmd_status` falls back to `status.json` and shows `SUBMITTED` indefinitely.
   - The fence is also empty, so it cannot be told apart from a genuine legacy claim. The prior review suggested writing the token into it.
   - Fix:
     - Write `token`, pid, boot_id and time into a file inside the fence before opening the database.
     - Have `status` and `reconcile` show `FENCED_NO_RECORD` when the fence exists but no row does.
2. **SIGHUP now overrides `nohup`.** If the controller was started with SIGHUP ignored (`nohup researchctl init-run …`), `execute` replaces that disposition with `terminate`. Closing the terminal then kills a run the operator explicitly detached.
   - This fails safe, and the state is recorded truthfully as `INTERRUPTED`, but it is surprising.
   - Fix: if `signal.getsignal(SIGHUP) is SIG_IGN`, leave SIGHUP ignored.
3. **The exit code can contradict the recorded state, and output can fail after a terminal hang-up.**
   - A signal that arrives after `finish(COMPLETED)` commits makes `execute` return `128 + sig`, while the registry says `COMPLETED`.
   - After a real tty hang-up, the final `print(..., flush=True)` raises `EIO`. `main`'s own `print(..., file=sys.stderr)` raises again, so the process exits 1 with no message.
   - In both cases the registry and projections are already correct; only the exit status is wrong.
   - Fix:
     - Compute the return code from the committed `end_state`.
     - Wrap the final print in `try/except OSError`.
4. **An inherited `SIGCHLD=SIG_IGN` breaks supervision.** If a parent leaves SIGCHLD ignored, the kernel reaps the leader automatically.
   - `waitid` then raises `ChildProcessError`, an `OSError`, so the code takes the `child is not None` branch.
   - That branch sends `killpg` to a pgid that is no longer pinned, so a pgid-reuse race becomes possible.
   - `Popen.wait` maps `ECHILD` to 0. The registry stays `RUNNING`, so this still fails closed.
   - Fix: set SIGCHLD to `SIG_DFL` before `Popen`.
5. **Unchanged from the prior review:** LOW-2 (handler install order), LOW-3 (official `BLOCKED` path), LOW-4 (`finish` from `DISPATCHING`), LOW-5 (corrupt registry in `status`). Details are in the table above.
6. **An optional evidence event on post-launch faults.** When `stop_and_reap()` runs because of an exception, a best-effort `events` insert would help an operator during reconcile, for example `detail='controller_error: <exc>; group SIGKILLed'`. It should not change state.

def now():
    return dt.datetime.now(dt.timezone.utc).isoformat(timespec="seconds")


def sha_file(path):
    digest = hashlib.sha256()
    with Path(path).open("rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()


def load_json(path):
    with Path(path).open(encoding="utf-8") as handle:
        return json.load(handle)


def atomic_json(path, payload):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    with tempfile.NamedTemporaryFile("w", encoding="utf-8", dir=path.parent,
                                     prefix=".pending-", delete=False) as temp:
        json.dump(payload, temp, indent=2, sort_keys=True)
        temp.write("\n")
        staged = Path(temp.name)
    os.replace(staged, path)


def settings():
    cfg = load_json(Path(os.getenv("HERDR_ML_CONFIG", str(DEFAULT_CONFIG))).expanduser())
    if cfg.get("version") != 1 or not isinstance(cfg.get("projects"), list):
        raise ResearchError("Invalid projects manifest")
    return cfg


def select_project(project_id):
    selected = next((p for p in settings()["projects"] if p.get("id") == project_id), None)
    if selected is None:
        raise ResearchError(f"Unknown project: {project_id}")
    directory = selected.get("directory", "")
    if not directory or Path(directory).name != directory or directory in (".", ".."):
        raise ResearchError("Unsafe project directory in config")
    if not project_id.replace("-", "").replace("_", "").isalnum():
        raise ResearchError("Unsafe project ID")
    root = Path(os.getenv("RESEARCH_ROOT", str(Path.home() / "research"))).expanduser().resolve()
    return selected, root / directory, root / ".runtime" / project_id


def git_metadata(checkout):
    if not (checkout / ".git").exists():
        return {"sha": None, "dirty": None}
    def git(*args):
        result = subprocess.run(["git", "-C", str(checkout), *args],
                                capture_output=True, text=True, check=False)
        return result.stdout.strip() if result.returncode == 0 else None
    sha = git("rev-parse", "HEAD")
    changed = git("status", "--porcelain")
    return {"sha": sha, "dirty": None if changed is None else bool(changed)}


def gate_report(checkout, gate_file=None):
    path = Path(gate_file).expanduser() if gate_file else checkout / ".research" / "gates.json"
    if not path.is_file():
        return {"valid": False, "path": str(path), "problems": ["Missing gate file"]}
    try:
        data = load_json(path)
    except (OSError, json.JSONDecodeError) as exc:
        return {"valid": False, "path": str(path), "problems": [f"Unreadable gate JSON: {exc}"]}
    entries = data.get("gates", {})
    errors = []
    if data.get("schema_version") != 1 or not isinstance(entries, dict):
        errors.append("Invalid gate schema")
        entries = {}
    for gate in REQUIRED:
        entry = entries.get(gate, {})
        if not isinstance(entry, dict) or entry.get("status") != "PASS":
            errors.append(f"{gate}: missing PASS verdict")
            continue
        if not entry.get("reviewer") or not entry.get("reviewed_at"):
            errors.append(f"{gate}: missing reviewer/date")
        evidence = entry.get("evidence")
        if not isinstance(evidence, list) or not evidence:
            errors.append(f"{gate}: missing evidence")
        else:
            for item in evidence:
                if not isinstance(item, str) or not item.strip():
                    errors.append(f"{gate}: invalid evidence item")
                    continue
                source = (checkout / item).resolve()
                if not source.is_relative_to(checkout.resolve()) or not source.is_file():
                    errors.append(f"{gate}: evidence missing/outside checkout: {item}")
    return {"valid": not errors, "path": str(path), "problems": errors}

    result = gate_report(checkout, args.gates)
    print(json.dumps(result, indent=2))
    return 0 if result["valid"] else 2


def cmd_status(args):
    _, _, runtime = select_project(args.project)
    runs = runtime / "runs"
    if not runs.is_dir():
        print("No runs found")
        return 0
    for folder in sorted(runs.iterdir()):
        if not folder.is_dir():
            continue
        try:
            submission = load_json(folder / "submission.json")
            registered = run_registry.inspect(folder)
            state = registered if registered is not None else load_json(folder / "status.json")
        except (OSError, json.JSONDecodeError):
            print(f"{folder.name}\tINVALID\tmissing/corrupt record")
            continue
        # Historical terminal JSON/registry records did not verify containment.
        label = state.get("state", "UNKNOWN")
        if label in ("CLAIMED", "DISPATCHING", "RUNNING", "COMPLETED", "FAILED", "INTERRUPTED"):
            label = "UNKNOWN"
        print(f"{folder.name}\t{label}\t{submission.get('mode')}")
    return 0


def cmd_reconcile(args):
    _, _, runtime = select_project(args.project)
    if not args.run_id or Path(args.run_id).name != args.run_id or args.run_id in (".", ".."):
        raise ResearchError("Unsafe run ID")
    folder = runtime / "runs" / args.run_id
    if not folder.is_dir():
        raise ResearchError("Unknown run")
    entry = run_registry.inspect(folder)
    if entry is None:
        result = {"state": "UNKNOWN", "reason": "No registry record; legacy or pre-claim run needs investigation"}
    elif entry["state"] in ("CLAIMED", "DISPATCHING", "RUNNING", "COMPLETED", "FAILED", "INTERRUPTED", "UNKNOWN"):

def require_supported_execution(mode, queue, *, submission=False):
    if mode != "diagnostic":
        raise ResearchError("Official or invalid execution BLOCKED: authenticated approval and immutable provenance not implemented")
    if (submission and queue != "local") or (not submission and queue is not None):
        raise ResearchError("Queued execution BLOCKED: process containment and daemon interpreter validation not implemented")


def cmd_init_run(args):
    project, checkout, runtime = select_project(args.project)
    argv = list(args.command)
    if argv and argv[0] == "--":
        argv.pop(0)
    if not argv:
        raise ResearchError("Supply executable and argv after --")
    if not (checkout / ".git").exists():
        raise ResearchError(f"Checkout missing: {checkout}; clone before running")
    if args.mode == "official":
        gate = gate_report(checkout, args.gates)
        if not gate["valid"]:
            raise ResearchError("Official run BLOCKED: " + "; ".join(gate["problems"]))
        if not args.approve_official:
            raise ResearchError("Official run requires --approve-official")
    if args.queue and args.queue != project.get("gpu_group", "gpu0"):
        raise ResearchError("Queue must match project GPU group (shared across all projects)")
    if args.queue and not args.approve_cost:
        raise ResearchError("Queued execution requires --approve-cost")
    require_supported_execution(args.mode, args.queue)
    git = git_metadata(checkout)
    if args.mode == "official" and (not git["sha"] or git["dirty"] is not False):
        raise ResearchError("Official runs require a clean, pinned Git checkout")

    run_id = dt.datetime.now(dt.timezone.utc).strftime("%Y%m%dT%H%M%SZ") + "-" + uuid.uuid4().hex[:12]
    folder = runtime / "runs" / run_id
    folder.mkdir(parents=True, exist_ok=False)
    submission = {
        "schema_version": 1, "run_id": run_id, "project": args.project,
        "mode": args.mode, "submitted_at": now(), "argv": argv,
        "working_directory": str(checkout), "git": git,
        "dataset_version": args.dataset_version, "split_hash": args.split_hash,
        "seed": args.seed, "queue": args.queue or "local",
        "python": sys.version.split()[0], "platform": platform.platform(),
        "gate_manifest": (str(Path(args.gates).resolve()) if args.gates else
                          str(checkout / ".research" / "gates.json")),
    }
    manifest = folder / "submission.json"
    atomic_json(manifest, submission)
    digest = sha_file(manifest)
    (folder / "submission.sha256").write_text(digest + "\n", encoding="utf-8")
    atomic_json(folder / "status.json", {"state": "QUEUED" if args.queue else "SUBMITTED",
                                         "updated_at": now()})
    cmd = [sys.executable, str(Path(__file__).resolve()), "_execute",
           "--project", args.project, "--run-id", run_id]
    if args.queue:
        if not shutil.which("pueue"):
            atomic_json(folder / "status.json", {"state": "SUBMISSION_FAILED",
                                                 "updated_at": now(), "error": "pueue missing"})
            raise ResearchError(f"Run {run_id}: Pueue not installed")
        # Pueue workers may not inherit the submitter's custom project root/config.
        cmd = ["env", "RESEARCH_ROOT=" + str(runtime.parent.parent),
               "HERDR_ML_CONFIG=" + str(Path(os.getenv("HERDR_ML_CONFIG",
                                                     str(DEFAULT_CONFIG))).expanduser().resolve()), *cmd]
        launch = subprocess.run(["pueue", "add", "-g", args.queue, "--", shlex.join(cmd)],
                                capture_output=True, text=True, check=False)
        if launch.returncode:
            atomic_json(folder / "status.json", {"state": "SUBMISSION_FAILED",
                         "updated_at": now(), "error": launch.stderr.strip()[:2000]})
            raise ResearchError(f"Run {run_id}: queue failed: {launch.stderr.strip()[:300]}")
        print(f"QUEUED run={run_id} folder={folder}")
        print(launch.stdout.strip())
        return 0
    print(f"STARTING run={run_id} folder={folder}", flush=True)
    return execute(args.project, run_id)


def execute(project_id, run_id):
    if signal.getsignal(signal.SIGCHLD) != signal.SIG_DFL:
        raise ResearchError("SIGCHLD disposition is not default; cannot safely pin and reap child identity")
    _, checkout, runtime = select_project(project_id)
    if not run_id or Path(run_id).name != run_id or run_id in (".", ".."):
        raise ResearchError("Unsafe run ID")
    folder = runtime / "runs" / run_id
    submission = load_json(folder / "submission.json")
    expected = (folder / "submission.sha256").read_text(encoding="utf-8").strip()
    actual = sha_file(folder / "submission.json")
    require_supported_execution(submission.get("mode"), submission.get("queue"), submission=True)
    if expected != actual or submission.get("project") != project_id:
        raise ResearchError("Submission manifest integrity mismatch")
    status_file = folder / "status.json"
    state = load_json(status_file).get("state")
    # Queued records, including legacy records called "local", remain held.
    if state != "SUBMITTED":
        raise ResearchError(f"Refusing execution: queued or repeated state={state}")
    try:
        token = run_registry.claim(folder, run_id, project_id, actual, state)
    except run_registry.RegistryError as exc:
        raise ResearchError(str(exc)) from exc
    if submission.get("mode") == "official":
        gate = gate_report(checkout, submission.get("gate_manifest"))
        current_git = git_metadata(checkout)
        if not gate["valid"] or current_git != submission.get("git") or current_git.get("dirty") is not False:
            atomic_json(status_file, {"state": "BLOCKED", "updated_at": now(),
                                      "error": "Gate invalid or source checkout changed since submission"})
            raise ResearchError("Official job BLOCKED: gates or pinned Git source changed")
    run_registry.advance(folder, token, "CLAIMED", "DISPATCHING")
    atomic_json(status_file, {"state": "DISPATCHING", "updated_at": now()})
    child = None
    interrupted = False
    interruption_signal = None
    group_owned = False

    def signal_group(sig):
        # The unreaped leader pins its PID/PGID. Never signal after reaping.
        if group_owned:
            try:
                os.killpg(child.pid, sig)
            except ProcessLookupError:
                pass

    def terminate(signum, _frame):
        nonlocal interrupted, interruption_signal
        interrupted = True
        interruption_signal = interruption_signal or signum
        signal_group(signal.SIGTERM)

    def stop_and_reap():
        nonlocal group_owned
        if group_owned:
            signal_group(signal.SIGKILL)
            # No process-group signal is sent after wait() reaps the leader.
            group_owned = False
            return child.wait()
        return None

    old_handlers = {sig: signal.signal(sig, terminate)
                    for sig in (signal.SIGTERM, signal.SIGINT, signal.SIGHUP, signal.SIGQUIT)}
    try:
        with (folder / "stdout.log").open("wb") as stdout, (folder / "stderr.log").open("wb") as stderr:
            try:
                if interrupted:
                    code = 128 + interruption_signal
                else:
                    child = subprocess.Popen(submission["argv"], cwd=checkout,
                                             stdin=subprocess.DEVNULL, stdout=stdout,
                                             stderr=stderr, shell=False, start_new_session=True)
                    group_owned = True
                    run_registry.record_child(folder, token, child.pid)
                    run_registry.advance(folder, token, "DISPATCHING", "RUNNING")
                    atomic_json(status_file, {"state": "RUNNING", "started_at": now(), "updated_at": now()})
                    if interrupted:
                        signal_group(signal.SIGTERM)
                    deadline = None
                    while True:
                        # WNOWAIT keeps the exited leader as a zombie, preventing
                        # its PID and process group ID from being reused.
                        result = os.waitid(os.P_PID, child.pid, os.WEXITED | os.WNOHANG | os.WNOWAIT)
                        if result is not None:
                            break
                        if interrupted and deadline is None:
                            deadline = time.monotonic() + 3
                        if deadline is not None and time.monotonic() >= deadline:
                            signal_group(signal.SIGKILL)
                        time.sleep(0.05)
                    code = stop_and_reap()
            except OSError as exc:
                if child is not None:
                    stop_and_reap()
                    raise
                stderr.write((str(exc) + "\n").encode("utf-8", errors="replace"))
                code = 127
            except BaseException:
                stop_and_reap()
                raise
        # Process groups cannot establish whether detached descendants survive.
        # Record the leader outcome without asserting whole-workload completion.
        leader_state = "INTERRUPTED" if interrupted else ("COMPLETED" if code == 0 else "FAILED")
        end_state = "UNKNOWN"
        result = {"state": end_state, "leader_state": leader_state,
                  "containment": "UNKNOWN", "exit_code": code, "leader_completed_at": now(),
                  "stdout_sha256": sha_file(folder / "stdout.log"),
                  "stderr_sha256": sha_file(folder / "stderr.log")}
        run_registry.finish(folder, token, result)
        atomic_json(folder / "result.json", result)
        atomic_json(status_file, {"state": end_state, "updated_at": now(), "exit_code": code})
        print(f"{end_state} run={run_id} exit={code} logs={folder}", flush=True)
        return 128 + interruption_signal if interrupted else (2 if code == 0 else (code if code >= 0 else 128 + abs(code)))
    finally:
        stop_and_reap()
        for sig, handler in old_handlers.items():
            signal.signal(sig, handler)

"""Transactional per-run ownership for a single trusted Linux host.

SQLite is authoritative; JSON files written by the runner are projections.
An active claim is never reclaimed here, even when its owner appears dead:
without verified containment, descendants may still be running.
"""
import json
import os
from pathlib import Path
import socket
import sqlite3
import uuid


class RegistryError(Exception):
    pass


def _connect(folder):
    db = sqlite3.connect(str(Path(folder) / 'registry.sqlite3'), timeout=30, isolation_level=None)
    db.execute('PRAGMA synchronous=FULL')
    db.execute('PRAGMA busy_timeout=30000')
    db.execute('''CREATE TABLE IF NOT EXISTS run (
        id INTEGER PRIMARY KEY CHECK (id = 1), run_id TEXT NOT NULL,
        project TEXT NOT NULL, manifest_sha256 TEXT NOT NULL,
        state TEXT NOT NULL, owner TEXT NOT NULL, owner_pid INTEGER NOT NULL,
        owner_host TEXT NOT NULL, owner_boot TEXT, owner_start TEXT,
        queue_task_id TEXT, result_json TEXT)''')
    db.execute('''CREATE TABLE IF NOT EXISTS child_identity (
        id INTEGER PRIMARY KEY CHECK (id=1), pid INTEGER NOT NULL,
        boot TEXT, start_ticks TEXT)''')
    db.execute('''CREATE TABLE IF NOT EXISTS events (
        seq INTEGER PRIMARY KEY AUTOINCREMENT, at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP,
        owner TEXT, state TEXT NOT NULL, detail TEXT)''')
    return db


def _identity():
    try:
        boot = Path('/proc/sys/kernel/random/boot_id').read_text().strip()
        stat = Path('/proc/self/stat').read_text()
        start = stat[stat.rfind(')') + 2:].split()[19]
    except (OSError, IndexError):
        boot, start = None, None
    return boot, start


def claim(folder, run_id, project, digest, initial_state):
    """Atomically create a run and claim it exactly once, never stealing owners."""
    if initial_state not in ('SUBMITTED', 'QUEUED'):
        raise RegistryError('Run is not eligible for execution')
    # Older deployed workers claim with mkdir. Acquire the same marker first,
    # atomically, so mixed versions cannot execute concurrently. Never delete
    # it automatically: a crash here needs manual investigation.
    try:
        (Path(folder) / 'execution.claim').mkdir(mode=0o700)
    except FileExistsError as exc:
        raise RegistryError('Execution already claimed; reconcile before retry') from exc
    directory = os.open(str(folder), os.O_RDONLY | os.O_DIRECTORY)
    try:
        os.fsync(directory)
    finally:
        os.close(directory)
    db = _connect(folder)
    token = uuid.uuid4().hex
    try:
        db.execute('BEGIN IMMEDIATE')
        if db.execute('SELECT 1 FROM run WHERE id=1').fetchone():
            raise RegistryError('Run already claimed; do not retry without reconciliation')
        boot, start = _identity()
        db.execute('INSERT INTO run VALUES (1,?,?,?,?,?,?,?,?,?,?,?)',
                   (run_id, project, digest, 'CLAIMED', token, os.getpid(),
                    socket.gethostname(), boot, start, None, None))
        db.execute('INSERT INTO events(owner,state,detail) VALUES (?,?,?)',
                   (token, 'CLAIMED', 'Atomic one-time owner acquisition'))
        db.execute('COMMIT')
        # Persist the new registry directory entry before any dispatch.
        directory = os.open(str(folder), os.O_RDONLY | os.O_DIRECTORY)
        try:
            os.fsync(directory)
        finally:
            os.close(directory)
        return token
    except BaseException:
        if db.in_transaction:
            db.execute('ROLLBACK')
        raise
    finally:
        db.close()


def record_child(folder, token, pid):
    """Record forensic identity; this is not evidence of containment."""
    try:
        boot = Path('/proc/sys/kernel/random/boot_id').read_text().strip()
        stat = Path('/proc/%d/stat' % pid).read_text()
        start = stat[stat.rfind(')') + 2:].split()[19]
    except (OSError, IndexError):
        boot, start = None, None
    db = _connect(folder)
    try:
        db.execute('BEGIN IMMEDIATE')
        if not db.execute("SELECT 1 FROM run WHERE id=1 AND owner=? AND state='DISPATCHING'", (token,)).fetchone():
            raise RegistryError('Stale owner or illegal child registration')
        db.execute('INSERT INTO child_identity VALUES (1,?,?,?)', (pid, boot, start))
        db.execute('INSERT INTO events(owner,state,detail) VALUES (?,?,?)',
                   (token, 'CHILD_IDENTIFIED', json.dumps({'pid': pid, 'boot': boot, 'start_ticks': start})))
        db.execute('COMMIT')
    except BaseException:
        if db.in_transaction:
            db.execute('ROLLBACK')
        raise
    finally:
        db.close()


def advance(folder, token, expected, target):
    if (expected, target) not in {('CLAIMED', 'DISPATCHING'), ('DISPATCHING', 'RUNNING')}:
        raise RegistryError('Illegal execution transition')
    db = _connect(folder)
    try:
        db.execute('BEGIN IMMEDIATE')
        updated = db.execute('UPDATE run SET state=? WHERE id=1 AND owner=? AND state=?',
                             (target, token, expected)).rowcount
        if updated != 1:
            raise RegistryError('Stale owner or illegal execution state')
        db.execute('INSERT INTO events(owner,state) VALUES (?,?)', (token, target))
        db.execute('COMMIT')
    except BaseException:
        if db.in_transaction:
            db.execute('ROLLBACK')
        raise
    finally:
        db.close()


def finish(folder, token, result):
    state = result.get('state')
    if state != 'UNKNOWN':
        raise RegistryError('Invalid terminal state')
    data = json.dumps(result, sort_keys=True)
    db = _connect(folder)
    try:
        db.execute('BEGIN IMMEDIATE')
        updated = db.execute("UPDATE run SET state=?, result_json=? WHERE id=1 AND owner=? AND state IN ('RUNNING','DISPATCHING')",
                             (state, data, token)).rowcount
        if updated != 1:
            raise RegistryError('Stale owner or illegal terminal state')
        db.execute('INSERT INTO events(owner,state,detail) VALUES (?,?,?)', (token, state, data))
        db.execute('COMMIT')
    except BaseException:
        if db.in_transaction:
            db.execute('ROLLBACK')
        raise
    finally:
        db.close()


def inspect(folder):
    path = Path(folder) / 'registry.sqlite3'
    if not path.is_file():
        return None
    db = _connect(folder)
    try:
        row = db.execute('SELECT run_id,project,manifest_sha256,state,owner_pid,owner_host,owner_boot,owner_start,queue_task_id,result_json FROM run WHERE id=1').fetchone()
        if row is None:
            return None
        fields = ('run_id','project','manifest_sha256','state','owner_pid','owner_host','owner_boot','owner_start','queue_task_id','result')
        result = dict(zip(fields, row))
        if result['result'] is not None:
            result['result'] = json.loads(result['result'])
        child = db.execute('SELECT pid,boot,start_ticks FROM child_identity WHERE id=1').fetchone()
        result['child'] = dict(zip(('pid','boot','start_ticks'), child)) if child else None
        result['events'] = [dict(zip(('seq','at','state','detail'), item)) for item in db.execute('SELECT seq,at,state,detail FROM events ORDER BY seq')]
        return result
    finally:
        db.close()

def legacy_claim(folder, start, results):

        results.put('lost')
