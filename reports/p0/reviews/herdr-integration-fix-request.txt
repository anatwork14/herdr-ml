## Live path findings (`researchctl.py`, `run_registry.py`)

### M1: Parsed argv is not bound to the hashed bytes (TOCTOU) — MEDIUM
**Root cause:** `execute` reads `submission.json` twice. `load_json()` parses one read, and `sha_file()` hashes a second read. The registry stores the digest of the second read, but `Popen` runs the argv from the first.
**Scenario:** Between the two reads, `submission.json` is replaced with a version whose hash matches `submission.sha256`. The run then executes argv A while the registry records the digest of manifest B.
**Context:** The `.sha256` file sits in the same writable directory, so this is a corruption check, not authentication. Anyone who can write the folder can already rewrite both files.
**Fix:** Read the bytes once, hash them, then parse those same bytes.

### M2: Log hashes are recorded while escaped descendants may still be writing — MEDIUM
**Root cause:** After the leader is reaped, `stdout_sha256` and `stderr_sha256` are computed immediately. A descendant that called `setsid()` survives the group `SIGKILL`, keeps the inherited log fds, and keeps appending.
**Scenario:** The workload spawns a detached logger and exits 0. `result.json` records hashes that no longer match the log files. The code marks `containment: UNKNOWN`, but the hashes still look final. Label them as a snapshot or omit them.

### M3: No platform guard; on non-Linux, a run is launched, killed, and wedged — MEDIUM (outside the declared platform)
**Root cause:** `os.waitid` does not exist on macOS. The `AttributeError` is raised after `Popen` and after the registry reaches `RUNNING`.
**Scenario:** On macOS, the claim succeeds and the workload starts. `except BaseException` then calls `stop_and_reap()` and SIGKILLs it. The registry stays `RUNNING` permanently, and `main` does not catch `AttributeError`, so the user sees a traceback.
**Fix:** Refuse at the start of `execute` unless running on Linux with `os.waitid` available.

### M4: Claims can be stranded with no operator resolution path — MEDIUM (gap)
Several points leave a run permanently claimed with no tooling to resolve it:
- A crash after `mkdir execution.claim`.
- A commit followed by a failed directory fsync. The claim is committed but no token is returned.
- A SIGINT before the handlers are installed. Handlers are installed after `advance(DISPATCHING)`, so the default handler raises `KeyboardInterrupt`, which `main` does not catch.

In all cases the registry is left at CLAIMED/DISPATCHING. `reconcile` only reports `UNKNOWN`. Failing closed is correct here, but the documented manual investigation procedure is missing.

### L1: `status` contradicts the claim marker — LOW
If a crash happens after `mkdir execution.claim` but before the registry row is committed, `inspect()` returns `None`. `cmd_status` then falls back to `status.json` and prints `SUBMITTED`, while `reconcile` reports `UNKNOWN`. `status` should treat an existing `execution.claim` as `UNKNOWN`.

### L2: One bad registry hides every run in `status` — LOW
The per-folder `except` in `cmd_status` catches `OSError` and `JSONDecodeError`, but not `sqlite3.Error`. A single corrupt registry, or one locked for more than 30 s, aborts the whole listing through `main`. Separately, `inspect()` goes through `_connect`, which issues DDL and pragmas, so it is not strictly read-only.

### L3: Unhandled `AttributeError` on non-object JSON — LOW
These all raise an uncaught `AttributeError` and a traceback. They fail closed, but noisily:
- a gates file that is a JSON list (`data.get`);
- a config file that is a list;
- non-dict project entries.

### L4: Durability is asymmetric — LOW
SQLite is durable (`synchronous=FULL`). The JSON projections are not:
- `atomic_json` never fsyncs the file or its directory.
- `submission.sha256` is written with a non-atomic `write_text`.
- The run folder's entry in `runs/` is never fsynced.

After a power loss, the forensic manifest can be empty, or the whole run folder can be missing, even though a workload was launched.

### L5: Exit code 2 is ambiguous — LOW
A successful leader returns 2 by design, since containment is unknown. But 2 is also the exit code for refusals, claim conflicts, and argparse errors. Automation cannot tell "ran, outcome unknown" apart from "never ran".

### L6: Diagnostic provenance is weak — LOW (documented limitation)
- Git state is captured at submission only, and `dirty` is a boolean.
- Nothing is re-captured at execution time.
- A `SUBMITTED` run that was never executed stays executable through `_execute` indefinitely, for example after `execute` refused on the SIGCHLD check. It would then run against whatever the checkout contains at that later time.

### Paths I checked that look correct
- **Signal races:** a signal before, during, or just after `Popen`; the `group_owned` toggle inside `stop_and_reap`.
- **Reap ordering:** `waitid(WNOWAIT)` keeps the zombie, the group is SIGKILLed, then `wait()` reaps.
- **Leader PGID:** `start_new_session` makes the leader a session leader, which cannot call `setpgid`, so its PGID stays pinned.
- **Child start-time parsing:** the `/proc/<pid>/stat` field index (starttime is index 19 after `)`).
- **Exactly-once:** `mkdir` together with the `id=1` row check.
- **Registry transitions:** the transition whitelist, and the `finish` guard on `RUNNING`/`DISPATCHING`.

## Standalone components

### `provenance.py` (not wired into anything)
- **P1 — MEDIUM:** The manifest and artifacts are not bound to the same directory instance. The manifest is opened by path, then each artifact re-opens `manifest_path.parent` by name. If the parent directory, or one of its ancestors (only the final component uses `O_NOFOLLOW`), is renamed or swapped between signature verification and hashing, artifacts are hashed from a different tree. **Fix:** open the parent directory fd once, `openat` the manifest relative to it, and reuse that fd for the artifacts.
- **P2 — LOW:** `os.open` runs before the `S_ISREG` check. With `O_NONBLOCK` this avoids hanging on a FIFO, but a device node inside the tree is still opened, which can have side effects. Check with `fstatat(AT_SYMLINK_NOFOLLOW)` first.
- **P3 — LOW:** Some failures on a validly signed manifest escape as non-`ProvenanceError` exceptions. Very large integer literals exceed `int_max_str_digits` and raise a plain `ValueError`, and deep nesting raises `RecursionError`. Exploiting this requires a signer.
- **Integration gap:** none of these is cross-checked against anything:
  - `project`;
  - `source_git_sha` against the `source` artifact;
  - `argv` against what actually runs.

  As the docstring says, verification is point-in-time and does not authorize execution.

### `herdr_reconcile.py` (no adapter)
- **L1 — HIGH if integrated: legacy workspaces are duplicated.**
  - **Root cause:** `_reject_untracked_workspace` only recognises labels carrying the `[herdr-ml:workspace:<32hex>]` marker. The old bootstrap created workspaces with plain labels and recorded them in `workspaces.tsv`. This module never reads that file.
  - **Scenario:** A user who ran the old bootstrap runs the new reconciler. It creates a second workspace for the same checkout.
  - **Fix:** Add a migration or adoption path, or block when any workspace's cwd equals the checkout.
- **L2 — HIGH if integrated: the meaning of `cwd` is unspecified.**
  - **Root cause:** If the adapter reports a pane's live cwd rather than the cwd it was created with, the checks break as soon as a user runs `cd`:
    - `_one` blocks with "different checkout".
    - `_reject_untracked_workspace` can wrongly attribute another project's checkout to this workspace and block that project.
  - **Fix:** The adapter contract must state which cwd it returns.
- **L3 — MEDIUM: missing tabs and missing workspaces are handled inconsistently.**
  - A missing workspace is BLOCKED. A recorded tab that is missing is silently recreated with the same deterministic label.
  - **Scenario:** `tabs()` returns a transient partial listing. A duplicate tab is created, and every later run blocks with "Multiple objects".
- **L4 — MEDIUM: a server restart has no recovery path.** Any change of identity blocks permanently. Deleting the state file does not help if Herdr restores the old workspaces, because `_reject_untracked_workspace` then blocks again. Routine reboots therefore need an adoption procedure that does not exist yet.
- **L5 — LOW: the identity check does not protect lazy listings.** The contract allows any iterable. In `_complete_intent`, `adapter.workspaces()` is followed by `_check_identity`; if it returns a generator, the real fetch happens during `_one`, after the second identity check, so the identity "sandwich" protects nothing. Materialise with `list()` before the post-check.
- **L6 — LOW:** A malformed state file (non-dict `tabs`, missing `token`) raises `AttributeError` or `KeyError` instead of `ReconcileBlocked`.

### `bootstrap-herdr.sh`
The hold is effective: `exit 2` runs before any side effect. The dead code below it still has the old unsafe pattern: no marker, a non-atomic TSV, and no intent journal. Delete it rather than relying on the hold staying in place.

--- scripts/herdr_reconcile.py ---
"""Crash-aware Herdr layout reconciliation core.

This module deliberately has no live Herdr adapter or command-line entry point.
The bootstrap safety hold remains in place until the actual server identity and
CLI data contracts are established and integration-tested in an authorized pane.

Adapter contract (a future adapter MUST obtain these values from the same server):
  identity() -> nonempty stable server/session incarnation identifier
  creation_cwd_verified() -> True only when adapter can establish immutable,
      server-provided creation-bound cwd for all workspaces and tabs; live pane
      cwd, caller assertions and unverifiable inferred paths are insufficient
  workspaces() -> iterable of {id, label, cwd}
  tabs(workspace_id) -> iterable of {id, label, cwd}
  create_workspace(label, cwd) -> None
  create_tab(workspace_id, label, cwd) -> None

A create may have taken effect even when it throws. The durable intent carries a
unique marker, allowing only a single verifiable match to be adopted. If an
uncertain create has no observable match, automatic retry is forbidden.
"""
import contextlib
import fcntl
import hashlib
import json
import os
import re
from pathlib import Path
import tempfile
import uuid


class ReconcileBlocked(Exception):
    """The next mutation cannot be made safely without operator investigation."""


def marker(prefix, token, name):
    return f"{name} [herdr-ml:{prefix}:{token}]"


def _canonical(path):
    return str(Path(path).expanduser().resolve(strict=True))


def _write(path, state):
    """Persist record and directory entry before issuing an external mutation."""
    path.parent.mkdir(parents=True, exist_ok=True, mode=0o700)
    temp_path = None
    try:
        with tempfile.NamedTemporaryFile('w', dir=path.parent, prefix='.state-',
                                         encoding='utf-8', delete=False) as temp:
            temp_path = temp.name
            os.fchmod(temp.fileno(), 0o600)
            json.dump(state, temp, sort_keys=True, indent=2)
            temp.write('\n')
            temp.flush()
            os.fsync(temp.fileno())
        os.replace(temp_path, path)
        temp_path = None
        fd = os.open(path.parent, os.O_RDONLY | os.O_DIRECTORY)
        try:
            os.fsync(fd)
        finally:
            os.close(fd)
    finally:
        if temp_path is not None:
            os.unlink(temp_path)


@contextlib.contextmanager
def _locked(path):
    path.parent.mkdir(parents=True, exist_ok=True, mode=0o700)
    with path.with_suffix(path.suffix + '.lock').open('a') as lock:
        fcntl.flock(lock, fcntl.LOCK_EX)
        try:
            yield
        finally:
            fcntl.flock(lock, fcntl.LOCK_UN)


def _one(objects, label, cwd):
    matches = [obj for obj in objects if obj.get('label') == label]
    if len(matches) > 1:
        raise ReconcileBlocked('Multiple objects have the same ownership marker')
    if not matches:
        return None
    obj = matches[0]
    if not isinstance(obj.get('id'), str) or not obj['id']:
        raise ReconcileBlocked('Object has no stable ID')
    try:
        actual = _canonical(obj['cwd'])
    except (KeyError, OSError, TypeError, ValueError) as exc:
        raise ReconcileBlocked('Object has no verifiable checkout') from exc
    if actual != cwd:
        raise ReconcileBlocked('Object marker exists at a different checkout')
    return obj['id']


def _check_identity(adapter, record):
    if adapter.identity() != record["server"]:
        raise ReconcileBlocked("Server/session identity changed during reconciliation")


def _reject_untracked_workspace(objects, label, checkout):
    # State may be lost while the corresponding live workspace survives. Never
    # create a new marker until the authoritative inventory proves there is no
    # workspace, including a legacy unmarked one, for this checkout, or a
    # managed workspace for this label. Conservative blocking also
    # covers an unavailable cwd, since ownership cannot then be disproved.
    pattern = re.compile(r'^(.*) \[herdr-ml:workspace:[0-9a-f]{32}\]$')
    for obj in objects:
        object_label = obj.get('label')
        match = pattern.fullmatch(object_label) if isinstance(object_label, str) else None
        try:
            existing_checkout = _canonical(obj['cwd'])
        except (KeyError, OSError, TypeError, ValueError) as exc:
            raise ReconcileBlocked(
                f"Workspace id={obj.get('id')!r} label={object_label!r} "
                'has unverifiable checkout; operator reconciliation required'
            ) from exc
        if existing_checkout == checkout or (match and match.group(1) == label):
            raise ReconcileBlocked('Workspace exists but local ownership state is missing')


def _complete_intent(adapter, record, state_path):
    """Resolve a persisted intent without ever blindly repeating a mutation."""
    _check_identity(adapter, record)
    pending = record['pending']
    if pending['kind'] == 'workspace':
        objects = list(adapter.workspaces())
    elif pending['kind'] == 'tab':
        objects = list(adapter.tabs(record['workspace_id']))
    else:
        raise ReconcileBlocked('Unknown pending operation')
    _check_identity(adapter, record)
    found = _one(objects, pending['label'], record['checkout'])
    if found is None:
        raise ReconcileBlocked('Ambiguous operation: no matching object; do not retry automatically')
    if pending['kind'] == 'workspace':
        record['workspace_id'] = found
    else:
        record['tabs'][pending['key']] = found
    record['pending'] = None
    _write(state_path, record)


def _intent_then_create(adapter, record, path, kind, label, key=None):
    _check_identity(adapter, record)
    record['pending'] = {'kind': kind, 'label': label, 'key': key}
    _write(path, record)
    # Exceptions, timeouts, process death, and malformed responses all leave the
    # durable intent intact. A later invocation must discover the outcome.
    _check_identity(adapter, record)
    if kind == 'workspace':
        adapter.create_workspace(label, record['checkout'])
    else:
        adapter.create_tab(record['workspace_id'], label, record['checkout'])
    _complete_intent(adapter, record, path)


def reconcile(adapter, state_path, project_id, label, checkout, tabs):
    """Reconcile one project. Caller supplies only authenticated adapter data.

    A failed identity, changed checkout, duplicate marker, or unknown mutation
    outcome is BLOCKED; this routine never deletes, renames, or focuses anything.
    """
    path = Path(state_path)
    if not isinstance(project_id, str) or not project_id or not isinstance(label, str) or not label:
        raise ValueError('Project identity and label are required')
    if not isinstance(tabs, (list, tuple)) or not tabs or any(not isinstance(t, str) or not t for t in tabs) or len(set(tabs)) != len(tabs):
        raise ValueError('Tabs must be a nonempty list of unique names')
    checkout = _canonical(checkout)
    if not (Path(checkout) / '.git').exists():
        raise ReconcileBlocked('Checkout is not a Git worktree')
    with _locked(path):
        try:
            cwd_verified = adapter.creation_cwd_verified()
        except (AttributeError, NotImplementedError) as exc:
            raise ReconcileBlocked('Creation-bound cwd capability unavailable') from exc
        if cwd_verified is not True:
            raise ReconcileBlocked('Creation-bound cwd capability unverified')
        identity = adapter.identity()
        if not isinstance(identity, str) or not identity:
            raise ReconcileBlocked('Server/session incarnation identity is unavailable')
        if path.exists():
            try:
                record = json.loads(path.read_text(encoding='utf-8'))
            except (OSError, ValueError) as exc:
                raise ReconcileBlocked('State cannot be read') from exc
            if not isinstance(record, dict) or record.get('version') != 1:
                raise ReconcileBlocked('Unknown state format')
            if (record.get('server') != identity or record.get('project') != project_id or
                    record.get('checkout') != checkout or record.get('label') != label):
                raise ReconcileBlocked('Stored project, checkout, label, or server identity changed')
        else:
            existing_workspaces = list(adapter.workspaces())
            if adapter.identity() != identity:
                raise ReconcileBlocked('Server/session identity changed during discovery')
            _reject_untracked_workspace(existing_workspaces, label, checkout)
            token = uuid.uuid4().hex
            record = {'version': 1, 'server': identity, 'project': project_id,
                      'label': label, 'checkout': checkout, 'token': token,
                      'workspace_id': None, 'tabs': {}, 'pending': None}
            _write(path, record)
        if record.get('pending'):
            _complete_intent(adapter, record, path)
        _check_identity(adapter, record)
        workspace_label = marker('workspace', record['token'], label)
        current_workspaces = list(adapter.workspaces())
        _check_identity(adapter, record)
        observed = _one(current_workspaces, workspace_label, checkout)
        if record['workspace_id'] is None:
            _reject_untracked_workspace(current_workspaces, label, checkout)
            if observed:
                raise ReconcileBlocked('Unrecorded workspace without matching intent')
            _intent_then_create(adapter, record, path, 'workspace', workspace_label)
        elif observed != record['workspace_id']:
            raise ReconcileBlocked('Workspace missing, moved, or ID reused')
        for tab_name in tabs:
            _check_identity(adapter, record)
            # Marker uses a digest rather than raw arbitrary input for stable uniqueness.
            tab_token = hashlib.sha256(tab_name.encode('utf-8')).hexdigest()[:16]
            tab_label = marker('tab', record['token'] + '-' + tab_token, tab_name)
            current_tabs = list(adapter.tabs(record['workspace_id']))
            _check_identity(adapter, record)
            observed = _one(current_tabs, tab_label, checkout)
            old = record['tabs'].get(tab_name)
            if old is not None and any(obj.get('id') == old and obj.get('label') != tab_label for obj in current_tabs):
                raise ReconcileBlocked('Tab ID reused for an unrelated object')
            if observed:
                if old is None or old != observed:
                    raise ReconcileBlocked('Unrecorded or replaced tab marker')
            else:
                _intent_then_create(adapter, record, path, 'tab', tab_label, tab_name)
        _check_identity(adapter, record)
        return {'workspace_id': record['workspace_id'], 'tabs': dict(record['tabs'])}

"""Mock-only reconciliation tests; never contact a Herdr server."""
import importlib.util
import json
from pathlib import Path
import tempfile
import unittest

spec = importlib.util.spec_from_file_location('herdr_reconcile', Path(__file__).resolve().parents[1] / 'scripts' / 'herdr_reconcile.py')
m = importlib.util.module_from_spec(spec)
spec.loader.exec_module(m)


class FakeHerdr:
    def __init__(self):
        self.server = 'server-incarnation-1'
        self.ws = []
        self.ts = {}
        self.next_id = 0
        self.fail_after = None
        self.fail_before = False
        self.calls = []

    def identity(self): return self.server
    def creation_cwd_verified(self): return True
    def workspaces(self): return list(self.ws)
    def tabs(self, workspace): return list(self.ts[workspace])
    def _id(self):
        self.next_id += 1
        return str(self.next_id)
    def create_workspace(self, label, cwd):
        self.calls.append('workspace')
        if self.fail_before: raise TimeoutError('before')
        wid = self._id()
        self.ws.append({'id': wid, 'label': label, 'cwd': cwd})
        self.ts[wid] = []
        if self.fail_after == len(self.calls): raise TimeoutError('after')
    def create_tab(self, workspace, label, cwd):
        self.calls.append('tab')
        if self.fail_before: raise TimeoutError('before')
        self.ts[workspace].append({'id': self._id(), 'label': label, 'cwd': cwd})
        if self.fail_after == len(self.calls): raise TimeoutError('after')


class ReconciliationTests(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.addCleanup(self.tmp.cleanup)
        self.root = Path(self.tmp.name)
        self.checkout = self.root / 'checkout'
        (self.checkout / '.git').mkdir(parents=True)
        self.path = self.root / 'state' / 'project.json'
        self.api = FakeHerdr()
        self.names = ['Control', 'Runs', 'Logs']

    def run_once(self):
        return m.reconcile(self.api, self.path, 'project', 'Project', self.checkout, self.names)

    def test_first_repeat_and_deleted_tab(self):
        first = self.run_once()
        self.assertEqual(first, self.run_once())
        self.assertEqual(self.api.calls, ['workspace', 'tab', 'tab', 'tab'])
        wid = first['workspace_id']
        self.api.ts[wid] = [t for t in self.api.ts[wid] if t['id'] != first['tabs']['Runs']]
        second = self.run_once()
        self.assertNotEqual(first['tabs']['Runs'], second['tabs']['Runs'])
        self.assertEqual(len(self.api.ws), 1)
        self.assertEqual(len(self.api.ts[wid]), 3)

    def test_crash_after_each_remote_mutation_recovers_without_duplicate(self):
        for stage in range(1, 5):
            with self.subTest(stage=stage), tempfile.TemporaryDirectory() as td:
                self.path = Path(td) / 'state.json'
                self.api = FakeHerdr()
                self.api.fail_after = stage
                with self.assertRaises(TimeoutError): self.run_once()
                self.api.fail_after = None
                result = self.run_once()
                self.assertEqual(len(self.api.ws), 1)
                self.assertEqual(len(self.api.ts[result['workspace_id']]), 3)
                self.assertEqual(len(self.api.calls), 4)

    def test_uncertain_absent_operation_is_never_retried(self):
        self.api.fail_before = True
        with self.assertRaises(TimeoutError): self.run_once()
        self.api.fail_before = False
        with self.assertRaises(m.ReconcileBlocked): self.run_once()
        self.assertEqual(self.api.calls, ['workspace'])

    def test_new_server_or_reused_id_blocks(self):
        result = self.run_once()
        self.api.server = 'server-incarnation-2'
        with self.assertRaises(m.ReconcileBlocked): self.run_once()
        self.api.server = 'server-incarnation-1'
        self.api.ws[0]['label'] = 'Unrelated workspace with reused ID'
        with self.assertRaises(m.ReconcileBlocked): self.run_once()
        self.assertEqual(self.api.ws[0]['id'], result['workspace_id'])

    def test_unverifiable_managed_workspace_identifies_operator_action(self):
        other_label = m.marker('workspace', 'a' * 32, 'other')
        self.api.ws.append({'id': 'w-stale', 'label': other_label,
                            'cwd': str(self.root / 'missing')})
        with self.assertRaises(m.ReconcileBlocked) as caught:
            self.run_once()
        message = str(caught.exception)
        self.assertIn('w-stale', message)
        self.assertIn(other_label, message)
        self.assertIn('operator reconciliation required', message)
        self.assertFalse(self.path.exists())
        self.assertEqual(self.api.calls, [])

    def test_reused_tab_id_blocks(self):
        result = self.run_once()
        tabs = self.api.ts[result['workspace_id']]
        next(t for t in tabs if t['id'] == result['tabs']['Runs'])['label'] = 'user tab'
        before = len(self.api.calls)

# Herdr reconciliation core (not connected to live CLI)

`scripts/herdr_reconcile.py` implements a mock-tested, fail-closed state machine. It is not a Herdr adapter and cannot bootstrap anything by itself. `scripts/bootstrap-herdr.sh` remains blocked. Do not remove the hold based on unit tests.

A future live adapter must authenticate and pin every read and mutation to the same actual Herdr server **incarnation**, not merely a socket path, server name, client-supplied token, process ID or session name. It must establish the installed CLI/API's server identity and actual workspace/tab metadata and make an atomic server identity check with every operation, or fail closed if that cannot be established. It must normalize API data to the contract in the module and produce complete, authoritative workspace and tab inventories with stable IDs, labels, and immutable server-provided creation-bound canonical cwd for workspaces and tabs. A live pane cwd can change and cannot prove workspace ownership. The adapter must implement `creation_cwd_verified()` and return the literal `True` only after verifying this capability; missing or false capability blocks all reconciliation. No live adapter has established this capability. A multi-call identity check in this core does not itself prevent a server swap inside a single adapter operation. API timeouts or missing/partial metadata must raise, never return an empty successful listing. A single canonical state path and shared locking protocol are required for all bootstrap invocations managing a given project and server; state and lock files must reside on a filesystem providing local `flock`, atomic rename, and fsync semantics. The protected state directory is part of the single-user trust boundary.

The core persists and fsyncs unique ownership markers and an operation intent before creating a workspace or tab. On restart, it adopts exactly one matching object only if its server, marker and checkout match. A missing object after an uncertain operation is **BLOCKED**, including the crash-before-dispatch case: lack of a result does not prove a remote mutation failed. Operator investigation and an audited recovery procedure are required; deleting state or retrying blindly is unsafe. When local state is missing, any existing workspace (including an unmarked legacy workspace) with the same canonical checkout, or a managed workspace with the same label, blocks before new state or a new workspace is created. Any workspace with an unverifiable checkout blocks even when its displayed label differs: its inaccessible path may be an alias of the requested checkout. The error identifies the workspace ID and label for operator reconciliation; do not discard it or infer that it is unrelated. Matching duplicate markers, changed identity, missing workspace, changed checkout and reused IDs also block. It never deletes, renames, focuses, or starts commands. The core restores a missing managed tab with a new ID only after a complete authoritative inventory and with no unresolved intent. Existing unrelated tabs are left intact.

Mock-only verification:

```sh
python3 -m unittest discover -s tests -p 'test_herdr_reconcile.py' -v
```

The tests exercise simulated API failures and actual abrupt exit of a mock client after each remote mutation. They do not prove installed Herdr compatibility, permissions, server incarnation identity, actual pane layout, or recovery on a live server. A real adapter and an authorized, isolated Herdr session are mandatory before release. Reconciliation of panes/watchers beyond existence of a tab remains unimplemented.
